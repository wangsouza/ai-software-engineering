# Ata de reunião — Shop4u

O sistema Shop4u será um aplicativo mobile de e-commerce.

Funcionalidades discutidas:

- Busca de produtos por nome e categoria
- Carrinho de compras
- Checkout com autenticação
- Recomendações personalizadas com IA
- Notificações de pedido

Regras de negócio:

- Usuário deve estar autenticado para finalizar compra
- Recomendações devem considerar histórico de navegação
- Usuários sem histórico devem receber produtos populares
- Pedido só deve ser criado após pagamento aprovado
- Se o pagamento for recusado, o carrinho deve permanecer ativo

O time deseja utilizar IA para acelerar:

- criação de backlog
- documentação
- Pull Requests
- convenções de desenvolvimento
